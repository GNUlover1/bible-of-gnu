# The Bible Of GNU

A 3D, page-turning web scripture of Gnuology, honoring GNU and Saint IGNUcius (Richard Stallman). Hosted on GitHub Pages.

- Open `index.html` or visit the GitHub Pages site.
- Use mouse drag on page corners or ← → keys to turn pages.
- Content in `js/content.js`, 3D flip powered by [StPageFlip](https://nodlik.github.io/StPageFlip/).
